# Liquid equilibrium image evaluation

The prepared batch is `renders/lab_3/liquid_equilibrium/`: eight questions, five images per question, using the existing experimental object registry. Objects retain their recorded cube shapes, colors and densities. New samples each have volume 60 mL.

The context shows one known-material cube partially floating at rest in a clear liquid in a transparent cubic tank on a laboratory workbench. The fraction submerged reveals the liquid density when combined with the density learned from the earlier experiment:

`liquid density = object density / submerged volume fraction`.

Each of the four choices shows the same four objects, one from each recorded material, at candidate resting positions. Exactly **one entire image** has every object correct. The other three change the state of one, two or three objects. Choices may be wrong about sinking versus floating, or about floating depth alone. No choice is an Unknown card.

Question text names no colors, specimen IDs, numerical object densities or liquid densities. There are no specimen-ID labels in the rendered scenes. Appearance must be matched to the experimental history. All questions use the same prompt. Correct letters A–D each occur twice across the initial eight questions.

## Render on CUDA

```bash
cd agent_reproduce
bash scripts/render/render_liquid_equilibrium.sh --device CUDA
```

This creates 40 PNGs under `questions/q001/` through `questions/q008/`. Each question has `context.png`, four choice images, a saved `scene.blend`, a review page, and parameter Markdown per image. Completed questions are skipped. Use `--rerender` to replace them. Standard `--samples` and `--resolution` arguments are available; Blender 3.6.23 is the supported local renderer.

The current visibility treatment uses a pale blue translucent liquid, a lightly shaded horizontal surface, thin outlines at the real water level along the tank walls and floating objects, low-reflection glass, and a neutral backdrop. Refraction is disabled for this measurement view so the submerged parts do not appear displaced or doubled. These are visual reading aids; the physical liquid density, specimen heights, displacement and correct answers are unchanged. The same treatment is applied to every option.

Old images from the previous reflective treatment are considered stale and will be regenerated by the render command. The pipeline requires the updated images. Per-image Markdown and build reports record the visual settings.

All scene geometry is prepared by code. No image model or paid API is used for rendering. Preparation and build-only checks do not render pixels.

After setting your API environment variables:

```bash

  --model 'YOUR_MODEL' \
```

## Physical assumptions and visual measurement

The tank has a 0.28 m cubic interior, 4 mm glass walls and an initial liquid depth of 0.17 m. The same liquid volume is used for context and each candidate arrangement. Surface height is recomputed from the displaced volume; multiple objects raise the surface. The rendered liquid mesh subtracts specimen volumes and is checked against the conserved liquid volume.

For a floating object, `submerged fraction = object density / liquid density`. Denser objects rest fully submerged on the tank bottom. The prepared liquid densities are 900, 1000, 1100, 1300, 1400, 1500, 1800 and 2000 kg/m³; these are host-only values. None equals a specimen's density, avoiding the nonunique resting height of neutral buoyancy.

Context objects are deliberately partially floating. A sunken context object would give only an inequality, and a fully submerged neutrally buoyant object would not have a unique height. Those cases are excluded from this initial infer-the-liquid-density task.

Thin guides keep each cube upright without friction or vertical support. This makes its submerged height fraction equal its submerged volume fraction and prevents free-floating cubes from rotating. Painted horizontal bands divide the cube into ten equal-volume layers; their geometry does not alter displacement. Guide displacement is treated as negligible, and guides are present in the same locations in all images. Objects are homogeneous, nonporous and nonabsorbing; surface tension and air buoyancy are ignored.

The renderer places all candidate objects in a separated row with the same horizontal arrangement across choices. It checks wall/floor clearance, object separation, camera framing and liquid volume. Scenes illustrate static equilibria and hypothetical distractors, not simulated fluid motion. Optical styling is identical across liquid densities and does not encode the density value.
