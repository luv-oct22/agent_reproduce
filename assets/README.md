# Robotics lab assets

The Franka Panda model is from [Google DeepMind MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie/tree/main/franka_emika_panda).
The upstream MJCF, visual/collision meshes, README and Apache-2.0 license are
preserved in `robots/franka_panda/`. Mesh geometry is unmodified. Our Blender
importer assigns its own surface materials and creates an animated joint hierarchy
from the MJCF body transforms. Collision meshes are retained for future use but
are **not** used for robot contact simulation in this renderer.

Wood maps are the 1K JPEG diffuse, roughness and OpenGL normal maps from
[Poly Haven wood_table_001](https://polyhaven.com/a/wood_table_001), distributed
under [CC0](https://polyhaven.com/license). Files were renamed to `Diffuse.jpg`,
`Rough.jpg` and `nor_gl.jpg`; pixel content is unchanged.

`manifest.json` records source URLs, licenses and SHA-256 hashes of all 73 files.
Run `python scripts/assets/fetch_lab_assets.py --verify` to check the local assets.
Omit `--verify` to download missing files. Existing modified files are never
overwritten; changed upstream downloads are rejected by their content hashes.

The room and furniture are generated by `src/simulation/robotics_room.py`.
The saved `renders/lab_1/original_distance/scene.blend` contains editable geometry,
joint animation, packed textures and asset-marked collections/materials. Add its
directory as a Blender Asset Library, or append the collections into another
scene. The Panda animation uses world coordinates for this particular experiment;
regenerate from YAML when changing the base or target positions.
